# B站评论过滤器 (bili-comment-filter)

这是一个 Tampermonkey 用户脚本，用于根据关键词和正则表达式过滤 Bilibili (B站) 评论区的评论。

## 功能

*   **关键词过滤:** 添加不想看到的关键词，包含这些关键词的评论将被过滤。
*   **正则表达式过滤:** 使用正则表达式进行更复杂的匹配和过滤。
*   **两种过滤模式:**
    *   **模糊显示 (默认):** 过滤掉的评论会变模糊，鼠标悬停可暂时查看。
    *   **直接隐藏:** 过滤掉的评论会被隐藏。
        *   **显示占位符:** 隐藏评论后，在原位置显示一个“已过滤评论，点击查看”的占位符，点击可恢复显示该条评论。
        *   **完全隐藏:** 隐藏评论且不显示任何占位符。
*   **设置面板:** 提供图形化界面，方便添加、删除过滤规则和切换过滤模式。
*   **多页面支持:** 支持视频页、专栏页、动态页。

## 安装

1.  **安装 Tampermonkey:** 首先，你需要在你的浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2.  **安装脚本:**
    *   点击 [这里](https://github.com/cmyyx/bili-comment-filter/raw/main/bili-comment-filter.user.js) ([GitHub仓库](https://github.com/cmyyx/bili-comment-filter))
    *   或者，将 `bili-comment-filter.user.js` 文件中的代码复制到 Tampermonkey 的新脚本编辑器中并保存。

## 使用方法

1.  安装脚本后，在 B 站的视频、专栏或动态页面，Tampermonkey 图标上会显示脚本已启用。
2.  点击浏览器右上角的 Tampermonkey 图标，在弹出的菜单中找到 “B站评论过滤器”，然后点击 “打开设置面板”。
3.  在设置面板中：
    *   切换 “关键词” 和 “正则表达式” 选项卡来管理不同类型的规则。
    *   在输入框中输入关键词或正则表达式，点击 “添加” 按钮。
    *   点击规则旁边的 “删除” 按钮来移除规则。
    *   在 “过滤设置” 区域选择你想要的过滤模式（模糊显示、直接隐藏、完全隐藏）。
4.  添加或修改规则后，脚本会自动重新应用过滤。


## 注意事项

*   正则表达式需要符合 JavaScript 的语法。
*   过滤规则保存在浏览器本地，清除浏览器数据可能会导致规则丢失。
*   B 站页面结构可能会更新，导致脚本失效。如果遇到问题，请检查是否有新版本或提交 issue。
